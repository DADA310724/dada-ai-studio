# DADA-AI

Premium Gemini-powered bilingual AI workspace.

Features:
- Bengali / English UI
- Dark / light theme
- Streaming chat
- Coding mode
- Research mode
- Gemini image generation
- Responsive mobile / desktop UI

Run:
1. npm install
2. Copy .env.example to .env.local
3. Put your Gemini key in GEMINI_API_KEY
4. npm run dev

For Vercel, add GEMINI_API_KEY in Project Settings > Environment Variables.
Do not paste the API key into ChatGPT or commit it to Git.
